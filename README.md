# ClearMind

A private T-break companion. One screen: how long you have been clean, and one
button for when you want to smoke.

Everything stays on the device. Nothing is sent anywhere unless you tap a send
button yourself.

## Install on Android (recommended)

Download the latest `.apk` from
[Releases](https://github.com/deveres97/clearmind-tracker/releases) and open it
on your phone.

The Android app can do what a web page cannot: notify you a few minutes before
your risky hours, check in morning and evening, keep the clean-time clock on
your lock screen, and put it on your home screen as a widget.

## Web version

<https://deveres97.github.io/clearmind-tracker/> — the same screens, but it can
only reach you while it is open.

## Repo

- `index.html`, `sw.js`, `manifest.webmanifest`, `img/` — the web version
- `android/` — the Android app; the same page lives in `app/src/main/assets/`
- `.github/workflows/android.yml` — builds the APK on every push
